# JOffice (Office XP Complete Suite in Pure Lean 4)

Microsoft Office XP (2002) 互換の完全機能・完全UIオフィススイートプロジェクト。

## コアスタック
- **Language**: Pure Lean 4
- **Character / ID System**: [Symbol32](file:///home/tasaburoyamada/sandbox/Symbol32)
- **Bytecode / AST Re-computation Engine**: [Lbir](file:///home/tasaburoyamada/sandbox/lbir)
- **Agent & Verification Framework**: [Nomos](file:///home/tasaburoyamada/sandbox/nomos)
